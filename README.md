# Rutina

## Rutina - ваш персональный помощник в формировании полезных привычек
Мобильное приложение, помогающее пользователю сделать привычки своей каждодневной рутиной

---

## Идея

Написать МП, где пользователь сможет придумать себе необходимую ему привычку(пример - учить английский каждый день по пол часа), и самостоятельно выставить период формирования привычки(рекомендовано 21 день). Согласно исследованиям именно столько требуется, чтобы укоренить какое-то действие в своём подсознании и сделать его своей рутиной . В качестве фичи написана нейросеть, которая выдаёт пользователю персональный совет в выполнении привычки

---

## Функционал пользователя

 - Регистрация новых пользователей и авторизация старых
 - Создание привычки
 - Получение совета от нейросети
 - Выполнение привычки по истечении срока формирования
 - Досрочное удаление привычки
 - Просмотр всех активных привычек и накопленных очков
